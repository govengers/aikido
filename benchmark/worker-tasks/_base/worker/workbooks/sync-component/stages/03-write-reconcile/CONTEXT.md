# Stage 03: write and reconcile

## Input
The extraction and the resolve block.

## Process
1. Overwrite `infra/<org>/<component>/inventory.md` with exactly this format (nothing else, no prose):

   ````markdown
   # <component> (<org>) inventory

   Generated by the `sync-component` workbook from `origin/main` of the component repo. Do not hand-edit.

   ## Source
   - Repo `repos/<repo>`, `origin/main` <sha7>, committed <dd.MM.yyyy>

   ## Applications
   | App | Stage | Namespace | Chart | Version |
   |-----|-------|-----------|-------|---------|
   | <app> | <stage> | <namespace> | <chart> | <version> |

   ## Open items
   - <bullet>
   ````

   One row per app and stage, sorted by app, then stage (both alphabetical). No `TODO.md` or no bullets: a single `- none`.
2. Reconcile the README: every fact the repo contradicts (namespace names, apps listed) gets corrected; list the corrections in the run report.
3. Update the component's row in `infra/README.md`: column `Last sync` = the run date `dd.MM.yyyy`.

## Output
```
inventory: <path>, <n> rows
README corrections: <list|none>
```

## Completion
Proceed to `04-learn`; the run is not done before it.
