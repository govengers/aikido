# Stage 05: learn

Follow `workbooks/_shared/learn/CONTEXT.md`. Incident-specific additions to the run report:

- Under "Task": the symptom and, in one sentence, the root cause with the evidence that proves it.
- Under "Suggested improvements": the proposed fix (unattended runs: the exact proposal from stage 03) and a detector or alert that would have caught this earlier.
- A known pattern: name the earlier run report (`journal/runs/<file>`) under "Task".
