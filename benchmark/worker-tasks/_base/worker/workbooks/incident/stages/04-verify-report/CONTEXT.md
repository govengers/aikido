# Stage 04: verify and report

## Input
Triage, diagnosis and fix blocks.

## Process
1. Applied fix: prove recovery with the symptom's own measure (pods Ready for N minutes, error lines gone from Loki). Proposed only: state that the incident is still open and what the proposal will change.
2. Report in at most ten lines: symptom, root cause, what was changed or proposed, how it was verified, what is still open. Timestamps `dd.MM.yyyy HH:mm` UTC.

## Output
The report.

## Completion
Proceed to `05-learn`; the run is not done before it.
